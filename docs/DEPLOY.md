# Установка сервера на VPS через MobaXterm

Инструкция рассчитана на VPS с Ubuntu 22.04+ или Debian 12+, где уже могут работать сайт на nginx и боты. Subly их не трогает: сервер слушает только `127.0.0.1:8090`, а наружу его отдаёт nginx на отдельном поддомене.

Установка занимает 15–20 минут, и большую часть времени уходит на ожидание DNS.

## Что понадобится

- VPS с доступом root по SSH (IP-адрес, логин и пароль или ключ от хостера);
- домен `antonshkel.ru` и доступ к его DNS (панель регистратора или хостера);
- [MobaXterm](https://mobaxterm.mobatek.net/download.html), бесплатной Home Edition достаточно;
- 1 ГБ свободной памяти и 2 ГБ диска на VPS.

## Шаг 1. DNS: поддомен для Subly

В панели, где настроен DNS домена, добавьте запись:

| Тип | Имя | Значение | TTL |
|---|---|---|---|
| A | `subly` | IP вашего VPS | 3600 (или по умолчанию) |

Запись начнёт работать через 15–60 минут. Пока она расходится, можно делать остальные шаги.

## Шаг 2. Подключиться к серверу в MobaXterm

1. Запустите MobaXterm и нажмите **Session** (слева сверху) → **SSH**.
2. В **Remote host** впишите IP сервера. Отметьте **Specify username** и впишите `root`. **Port**: `22` (или тот, что дал хостер).
3. Если вход по ключу, откройте вкладку **Advanced SSH settings** → **Use private key** и выберите файл ключа.
4. Нажмите **OK**. При первом входе MobaXterm спросит пароль и предложит его сохранить, с этим можно согласиться.

Откроется чёрное окно терминала. Слева появится панель SFTP с файлами сервера. Через неё можно перетаскивать файлы мышкой, и она пригодится для резервных копий.

> Текст в терминал MobaXterm вставляется правой кнопкой мыши или `Shift+Insert`. `Ctrl+V` в терминале не работает.

## Шаг 3. Скачать Subly и запустить установку

Вставьте по очереди:

```bash
apt-get update && apt-get install -y git
cd /root
git clone https://github.com/antonshkelll/Subly.git
cd Subly
sudo bash deploy/setup.sh
```

Скрипт спросит:

1. Почту администратора. Это адрес, на который вы потом зарегистрируетесь в приложении, с ним откроется админка.
2. shopId и секретный ключ ЮKassa. Можно нажать Enter и подключить оплату позже (шаг 6).

Потом скрипт сам:

- поставит Docker, nginx и certbot, если их нет;
- создаст папку `/opt/subly` и файл настроек `.env` со случайными паролями;
- скачает последнюю версию сервера из GitHub Releases, так что собирать на VPS ничего не нужно;
- запустит PostgreSQL и сервер в контейнерах и дождётся ответа `/health`;
- добавит сайт `subly.antonshkel.ru` в nginx;
- выпустит SSL-сертификат, если DNS уже работает.

В конце появится «Готово» и адреса сайта и админки.

## Шаг 4. SSL, если DNS ещё не обновился

Если скрипт написал «Домен пока не указывает на этот сервер», подождите 15–60 минут и выполните:

```bash
cd /root/Subly
sudo bash deploy/setup.sh --ssl
```

Чтобы проверить, откройте в браузере https://subly.antonshkel.ru. Должен открыться лендинг с замком в адресной строке.

## Шаг 5. Первый вход

1. Установите APK на телефон: https://subly.antonshkel.ru/download (пока сервер не запущен, APK можно взять в [релизах на GitHub](https://github.com/antonshkelll/Subly/releases/latest)).
2. Зарегистрируйтесь на почту администратора.
3. Откройте https://subly.antonshkel.ru/admin и войдите с той же почтой и паролем. В админке видны пользователи, подписки, платежи и регистрации по дням.

## Шаг 6. Подключить ЮKassa

1. Зарегистрируйтесь на [yookassa.ru](https://yookassa.ru). Для приёма платежей нужен статус самозанятого или ИП. Для проверки хватит тестового магазина: он создаётся сразу, и деньги в нём не списываются.
2. В личном кабинете откройте **Интеграция → Ключи API** и выпустите секретный ключ. Там же виден `shopId`.
3. В разделе **Интеграция → HTTP-уведомления** укажите URL `https://subly.antonshkel.ru/api/billing/yookassa/webhook` и события `payment.succeeded` и `payment.canceled`.
4. На сервере выполните:

   ```bash
   cd /root/Subly
   sudo bash deploy/setup.sh --reconfigure
   ```

   Введите shopId и ключ, после этого сервер перезапустится.

5. В приложении откройте Профиль → Subly Pro → Оплатить. В тестовом магазине нужна тестовая карта из [документации ЮKassa](https://yookassa.ru/developers/payment-acceptance/testing-and-going-live/testing). Там перечислены номера карт для успешной и отклонённой оплаты, срок действия подойдёт любой в будущем.

> Самозанятым ЮKassa может сама отправлять чеки в «Мой налог». Включите это в настройках магазина, чтобы не формировать чеки вручную.

## Обновление

Новая версия выпускается в GitHub: **Actions → Release → Run workflow**, где нужно ввести номер (например, `1.0.1`). Через 5–7 минут появится релиз с новым APK и сервером. Затем на VPS:

```bash
cd /root/Subly
git pull
sudo bash deploy/setup.sh --update
```

Скрипт скачает новый jar, перезапустит сервер и сохранит прошлую версию для отката.

## Команды

| Команда | Что делает |
|---|---|
| `sudo bash deploy/setup.sh` | Первая установка |
| `sudo bash deploy/setup.sh --update` | Обновить сервер до последнего релиза |
| `sudo bash deploy/setup.sh --ssl` | Выпустить SSL, когда заработал DNS |
| `sudo bash deploy/setup.sh --reconfigure` | Поменять почту админа и ключи ЮKassa |
| `sudo bash deploy/setup.sh --status` | Состояние контейнеров и ответ `/health` |
| `sudo bash deploy/setup.sh --logs` | Журнал сервера в реальном времени (выход — `Ctrl+C`) |
| `sudo bash deploy/setup.sh --backup` | Копия базы в `/opt/subly/backups` |
| `sudo bash deploy/setup.sh --restart` | Перезапустить сервер |

Резервную копию удобно скачать на компьютер через панель SFTP слева в MobaXterm: откройте `/opt/subly/backups` и перетащите файл на рабочий стол.

## Что где лежит

| Путь | Что это |
|---|---|
| `/opt/subly/.env` | Настройки и ключи (права 600, только root) |
| `/opt/subly/subly-server.jar` | Сервер; `.prev` — прошлая версия |
| `/opt/subly/pgdata` | Файлы базы PostgreSQL |
| `/opt/subly/backups` | Резервные копии |
| `/etc/nginx/sites-available/subly.conf` | Сайт в nginx (certbot дописывает туда SSL) |
| `/var/log/nginx/subly.access.log` | Журнал запросов |

## Если что-то не работает

- `502 Bad Gateway` на сайте значит, что сервер не запущен. Выполните `sudo bash deploy/setup.sh --status`, затем `--logs`.
- Если приложение пишет «Нет связи с сервером», проверьте, что https://subly.antonshkel.ru/health открывается в браузере телефона и отвечает `{"status":"ok","db":true}`.
- Если certbot не выпускает сертификат, то либо DNS ещё не обновился (`ping subly.antonshkel.ru` должен показать IP сервера), либо порт 80 закрыт файрволом: `ufw allow 80,443/tcp`.
- Если оплата прошла, а Pro не включился, нажмите в приложении Профиль → «Проверить оплату». Сервер сам спросит статус у ЮKassa, даже если вебхук не дошёл.
- Если на VPS мало памяти: сервер ограничен 256 МБ (`-Xmx256m` в `docker-compose.yml`), PostgreSQL занимает ещё около 50 МБ.
