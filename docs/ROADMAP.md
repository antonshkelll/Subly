# План развития и внедрения

## Для кого

| Сегмент | Боль | Что даёт Subly |
|---|---|---|
| Студенты и молодые специалисты, 18–30 | 5–8 подписок по 199–999 ₽, бюджет ограничен | Итог в месяц, советы, от чего отказаться |
| Семьи | Подписки на разных людей и картах, дубли | Видно все сервисы в одном месте, дубли по категориям |
| Фрилансеры | ChatGPT, Figma, хостинг, домены — рабочие расходы | Экспорт в CSV для учёта, напоминания о продлении доменов и VPS |

Главное обещание: **«За три минуты узнайте, сколько стоят ваши подписки, и больше не пропускайте списания»**.

## Этап 0 — запуск (готово)

- [x] Android-приложение: учёт подписок, итог, категории, ближайшие списания, напоминания
- [x] Сервер, синхронизация между устройствами, удаление аккаунта
- [x] Pro через ЮKassa, советы, экспорт CSV
- [x] Админка с ключевыми метриками, лендинг с SEO-разметкой
- [x] Установка на VPS одной командой, CI, релизы по тегу

## Этап 1 — первые 100 пользователей (2–4 недели)

Цель: проверить, что людям это нужно. Главная метрика — **доля пользователей, которые добавили 3+ подписки в первый день** (активация). Ориентир — 40%.

1. Развернуть сервер (`docs/DEPLOY.md`), выпустить релиз `v1.0.0`.
2. Раздать APK знакомым и однокурсникам, собрать 15–20 отзывов голосом или в Telegram.
3. Пост на Хабре: «Сделал трекер подписок на Kotlin и Ktor — что узнал про ЮKassa и Compose на слабых телефонах». Технический пост приводит и пользователей, и работодателей.
4. Посты в студенческих чатах и каналах о личных финансах — с вопросом «сколько у вас уходит на подписки?» и ссылкой на лендинг.
5. Каждую неделю смотреть в админке: регистрации, «Ведут подписки», среднее число подписок на человека.

## Этап 2 — удобство (1–2 месяца)

- **Виджет на рабочий стол** (Glance): сумма в месяц и ближайшее списание.
- **Мультивалютность**: подписки в долларах и евро с пересчётом по курсу ЦБ (API ЦБ бесплатный).
- **Семейный доступ** (Pro): общий список на двоих-четверых, видно, кто за что платит.
- **История цен**: если сервис поднял тариф, Subly покажет, на сколько выросли траты за год.
- **Пуш через FCM/RuStore Push** в дополнение к локальным уведомлениям: письмо-дайджест «в этом месяце спишется N ₽».
- **Импорт из CSV** и шаблоны популярных тарифов с актуальными ценами (обновляются с сервера, без новой версии приложения).

## Этап 3 — рост (3–6 месяцев)

- Публикация в **RuStore**, затем в **Google Play**.
- **Реферальная программа**: месяц Pro за приглашённого друга, который добавил 3+ подписки.
- **Web-версия** на том же API для тех, кто ведёт бюджет с компьютера.
- **Автопродление Pro** через сохранённый способ оплаты ЮKassa (нужно согласование с ЮKassa и явная галочка у пользователя).
- **Миграции базы** через Flyway вместо автосоздания таблиц, метрики сервера в Prometheus + Grafana.

## Метрики продукта

| Метрика | Как считать | Ориентир |
|---|---|---|
| Активация | Добавили 3+ подписки в день регистрации / все регистрации | 40% |
| Retention D7 / D30 | Открыли приложение через 7 / 30 дней | 25% / 15% |
| Подписок на пользователя | В админке: «Подписок в базе / Ведут подписки» | 5+ |
| Конверсия в Pro | Pro / все пользователи (в админке) | 3–5% |
| ARPPU | Выручка / платящие за месяц | ~120 ₽ (доля годовых тарифов) |
| Сэкономлено пользователями | Сумма удалённых подписок, отменённых после совета | Главная метрика ценности |

Для D7/D30 и активации нужно хранить даты входов — это первая задача этапа 2: таблица `events (user_id, type, created_at)` и пара графиков в админке.

## Риски

- **Людям лень вносить подписки руками.** Ответ: популярные сервисы в один тап, а в будущем — импорт из CSV банковской выписки (без доступа к банку).
- **Напоминания режут производители телефонов** (Xiaomi, Huawei «убивают» фоновые задачи). Ответ: подсказка в приложении, как добавить Subly в исключения, и серверные пуши на этапе 2.
- **Цены сервисов меняются.** Ответ: шаблоны тарифов с сервера, обновление без новой версии APK.
